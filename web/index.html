What is included

Clinical scope

Demographics, BMI, Epworth scores, AHI, snoring, oxygenation, symptoms, upper-airway findings, comorbidities, and occlusion findings.

Language-neutral analysis

ASCII snake_case headers and compact per-column codes support interoperable analysis without embedding verbose labels in the data table.

Reversible encoding

Companion JSON dictionaries map every categorical code to its source label. Missing values are represented as NA.

Responsible research use

Describe the cohort before comparing it.

The supplied data describe an observed cohort. The repository provides descriptive statistics and reproducible figures for comparison with other research, but the dataset should not be presented as representative of a wider patient population without an external reference population, documented sampling design, or appropriate weighting.

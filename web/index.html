Dataset Overview

The Orofacial Myofunctional Therapy Dataset for Obstructive Sleep Apnea supports the study “Artificial Intelligence-Enhanced Telemedicine for Orofacial Myofunctional Therapy in Sleep Apnea: Adult Patient Outcomes”. It contains anonymised clinical and treatment-response data from 87 adult patients who underwent AI-assisted Orofacial Myofunctional Therapy (OMT) using the Smart Therapy Manager® system.

Study period: November 2021 - November 2022
Location: NEUMOMED Clinic, Medellín, Colombia
Sample size: 87 patients
Data formats: CSV, XLSX, TTL, XML, JSON

Data Contents

The dataset is split into two main parts:

  • Clinical data - anonymised patient records (age, sex, diagnosis, treatment response, etc.).
  • Metadata - a CSV file describing the variables, units, and coding scheme.

All files are located in data/external/raw/ and are freely downloadable from the GitHub repository.

Machine-Readable Metadata

The dataset follows FAIR principles and provides metadata in several interoperable formats:

  • DCAT-TTL
  • Schema.org JSON-LD
  • JSON-Schema
  • DOI
  • ORCID IDs

The Frictionless Data Package describes the structure of the data files and can be used by tools such as datapackage-py.

FAIR Compliance

The dataset adheres to the FAIR Data Principles (Findable, Accessible, Interoperable, Reusable). For a detailed breakdown, see the FAIR.md file.

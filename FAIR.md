# FAIR Statement

The **ST-OSA-PS-OMT-Theraphy-Data** dataset follows the **FAIR Data Principles** to promote **Findability, Accessibility, Interoperability, and Reusability** of research data.

---

## 🔍 Findable

| Principle | Implementation                                                                                                                                                    |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **F1**    | The dataset is assigned a globally unique and persistent identifier (DOI: `10.1016/j.rmed.2025.108460`).                                                          |
| **F2**    | Rich, contextual metadata is provided in multiple machine-readable formats, including DCAT-TTL, Schema.org JSON-LD, JSON Schema, and a Frictionless Data Package. |
| **F3**    | The dataset identifier is explicitly included in all metadata files, including `CITATION.cff`, `metadata_schema.json`, `schemaorg.jsonld`, and `dcat.ttl`.        |
| **F4**    | The dataset and its metadata are indexed and discoverable through searchable resources, including GitHub, Zenodo, and the Open Science Framework.                 |

---

## 🔓 Accessible

| Principle | Implementation                                                                                                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A1**    | The dataset and associated metadata are retrievable using open, standardized protocols such as HTTP and Git.                                                                             |
| **A1.1**  | No authentication or authorization barriers are required to access the publicly released dataset or its metadata.                                                                        |
| **A1.2**  | Metadata is maintained independently of the data files and remains accessible even if individual data files are removed or relocated.                                                    |
| **A2**    | The dataset is released under the **Creative Commons Attribution 4.0 International (CC BY 4.0)** license, permitting reuse, redistribution, and adaptation with appropriate attribution. |

---

## 🔄 Interoperable

| Principle | Implementation                                                                                                                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **I1**    | Data and metadata are provided in standard, widely used formats, including CSV, XLSX, TTL, XML, and JSON.                                                                                                                                                           |
| **I2**    | Metadata is available in both human-readable formats (Markdown and README documentation) and machine-readable formats (JSON-LD, DCAT-TTL, and JSON Schema).                                                                                                         |
| **I3**    | Terminology and metadata are aligned with relevant community standards. Clinical variables use **Clinical Data Interchange Standards Consortium (CDISC)** terminology where applicable, while the dataset is described using the **Schema.org Dataset** vocabulary. |

---

## 🔁 Reusable

| Principle | Implementation                                                                                                                                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **R1**    | The dataset is comprehensively documented through a detailed `README.md`, data dictionary (`docs/data_dictionary.md`), methodology documentation (`methodology.md`), and quality report (`docs/quality_report.md`). |
| **R1.1**  | The **CC BY 4.0** license permits reuse, redistribution, and adaptation provided that appropriate attribution is given.                                                                                             |
| **R1.2**  | Data provenance and dataset history are documented through `CITATION.cff`, `metadata_schema.json`, and `dcat.ttl`, including authorship, affiliations, and version information.                                     |
| **R1.3**  | The dataset follows domain-relevant standards for clinical research reporting and data sharing and is designed in accordance with the FAIR Data Principles.                                                         |
